# CITA - Indice de citas de errores resueltos

Este archivo es un indice. Cada fila apunta a un archivo
docs/citas/CITA-0XX.md con el detalle de un error real que se
investigo y resolvio en este proyecto.

No se crean entradas especulativas ni por anticipado: una CITA-0XX.md
se escribe solo cuando un error real ya fue diagnosticado y resuelto.
Ver docs/citas/README.md para el criterio completo.
